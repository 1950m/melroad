# sampledata — 시뮬레이션(가상) 주행 데이터

DEMO 모드의 주행 데이터는 `core-music/src/main/kotlin/.../music/DriveFixtures.kt`에서 구간 규칙으로 생성한다.
모두 **합성 데이터**이며 실제 도로·실시간 센서 기록이 아니다.

| id | 화면 이름 | 길이 | 특징 |
|---|---|---|---|
| coast | 테스트 1 (해안도로 흐름) | 약 5분 | 완만한 좌우 굽이, 25초 정차, S자 굽이, 해안 언덕 오르막·내리막. 정제 검증용으로 위치 신호 15초 끊김과 GPS 튐 1회를 의도적으로 포함 |
| hill | 테스트 2 (언덕길) | 약 4분 | 지속 오르막(최대 +1.5 m/s), 급한 굽이(±12°/s), 내리막 |
| city | 테스트 3 (도심) | 약 4분 | 신호 대기(정차)와 출발 반복, 좌·우회전 |

- 테스트 1은 해안도로의 흐름을 본뜬 가상 경로이며 실제 도로 형상·좌표와 일치하지 않는다.
- 샘플 주기 1초, 잡음은 seed 기반이라 실행할 때마다 같은 데이터가 만들어진다.
- 앱 화면·저장 데이터에는 항상 "시뮬레이션"으로 표시된다.
